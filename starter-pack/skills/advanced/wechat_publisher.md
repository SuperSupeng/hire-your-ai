# 公众号一键发布

## 前置配置
> 首次使用前需要授权公众号：
> 1. 在 OpenClaw 设置 → 工具 → 微信公众号 中，扫码授权你的公众号
> 2. 授权完成后，数字员工就有了"登录你的公众号后台"的能力
> 3. 只需授权一次，后续自动调用
>
> ⚠️ 安全说明：授权仅开放"文章发布"权限，不会触碰粉丝数据、财务信息或其他敏感操作。

## 任务目标
将用户提供的文章内容（纯文字或 Markdown 格式），自动排版并发布到微信公众号。

## 执行步骤

### 阶段一：内容检查
1. 接收用户提供的文章内容
2. 检查文章的完整性：
   - 是否有标题？
   - 是否有正文内容？
   - 是否有明显的格式错误（如 Markdown 语法未闭合）？
3. 如果有问题，提醒用户补充；如果没问题，进入下一步

### 阶段二：排版处理
4. 将文章内容转换为公众号友好的排版格式：
   - 标题层级转换（# → 大标题，## → 小标题）
   - 段落间距适配手机阅读
   - 加粗、引用等格式正确渲染
   - 图片链接转为公众号图片（如有）
5. 生成排版预览，让用户确认

### 阶段三：发布设置
6. 询问用户发布偏好（如果用户没主动说明）：
   - **封面图**：使用文章中的第一张图 / 自动从图库选择 / 用户指定
   - **摘要**：自动从文章开头提取 / 用户自定义
   - **发布时间**：立即发布 / 定时发布（指定时间）
   - **原创声明**：是否勾选原创

### 阶段四：执行发布
7. 调用公众号发布工具，执行以下操作：
   - 登录公众号后台
   - 新建图文消息
   - 填入标题、正文、摘要、封面
   - 根据用户选择：立即群发 / 保存为草稿 / 设定定时发布
8. 返回发布结果确认

## 输出格式

**发布前确认**
- 标题：[文章标题]
- 字数：[XX] 字
- 封面：[封面图来源]
- 摘要：[摘要内容]
- 发布方式：[立即发布 / 定时发布 / 保存草稿]

确认无误请回复"发布"，我立刻执行。

**发布结果**
- ✅ 发布成功！
- 文章链接：[公众号文章链接]
- 发布时间：[时间]

> ⚠️ 安全机制：在你明确说"发布"之前，文章只会保存为草稿，不会自动群发。
