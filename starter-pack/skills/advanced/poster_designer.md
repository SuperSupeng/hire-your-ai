# 海报设计师

## 前置配置
> 首次使用前需要配置 AI 绘图工具。在 OpenClaw 设置 → 工具 → 图片生成 中，
> 接入你偏好的 AI 绘图服务（如 DALL·E、Midjourney、Flux 等）。
> 只需配置一次，后续自动调用。

## 任务目标
根据用户描述的需求，生成专业级的活动海报、荣誉证书、社交媒体 Banner 等视觉设计图。

## 执行步骤
1. 确认用户的设计需求，提取关键信息：
   - **设计类型**：活动海报 / 荣誉证书 / 社交媒体 Banner / 邀请函 / 宣传单页
   - **核心文案**：标题、副标题、时间地点等必须出现的文字
   - **风格偏好**：商务简约 / 科技感 / 活泼可爱 / 中国风 / 极简等
   - **尺寸用途**：朋友圈海报（1080×1920）/ 公众号封面（900×383）/ A4 打印 / 自定义
   - 如果用户没说全，先追问确认关键信息，不要自己编造内容

2. 根据需求生成详细的设计描述（Prompt），包含：
   - 整体布局和构图方向
   - 配色方案（根据风格自动推荐）
   - 主视觉元素和装饰元素
   - 文字排版位置和层级关系

3. 调用 AI 绘图工具生成设计图

4. 输出设计图 + 设计说明（方便用户后续微调）

## 输出格式

**设计方案**
- 类型：[海报/证书/Banner...]
- 尺寸：[宽 × 高]
- 风格：[风格描述]

**生成结果**
[AI 生成的设计图]

**设计说明**
- 配色：[主色 + 辅色 + 点缀色]
- 字体建议：标题用 [XX]，正文用 [XX]
- 如需修改：告诉我"标题再大一点""换成蓝色调""加一个二维码位置"等，我重新生成

> 💡 生成的图片可以直接用于社交媒体发布。如果需要精细排版（比如加上精确的文字），建议用 Canva 或 PPT 在生成的底图上叠加文字层。
