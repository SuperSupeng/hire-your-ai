# 妙记秒变纪要

## 前置配置
> 本技能需要飞书 CLI（lark-cli）已安装并完成授权。
> 安装方式：在终端执行 `npm install -g @anthropic-ai/lark-cli`
> 授权方式：执行 `lark-cli auth login`，扫码登录你的飞书账号
> 只需操作一次，后续自动调用。详见附录 B。

## 任务目标
用户开完飞书会议后，只需说一句话，数字员工就自动从飞书妙记中拉取会议录音转写内容，整理成结构清晰的会议纪要。

**跟即用技能里的「会议纪要整理官」有什么区别？**
- 会议纪要整理官：你需要**手动复制粘贴**会议记录或转写文本给它
- 妙记秒变纪要：它**自己去飞书妙记里拉取**，你什么都不用复制

## 执行步骤

### 阶段一：定位会议
1. 用户说"帮我整理刚才那个会的纪要"或"整理今天下午 2 点那个会议"
2. 使用 `lark-cli minutes` 获取最近的会议列表
3. 根据用户描述的时间或关键词，匹配到对应的会议
4. 如果匹配到多个，列出让用户选择；如果只有一个，直接进入下一步

### 阶段二：拉取转写
5. 使用 `lark-cli minutes` 获取该会议的完整转写文本
6. 同时获取会议的参会人信息（从飞书日历/会议记录中）

### 阶段三：生成纪要
7. 从转写文本中提取：
   - **会议基本信息**：日期、时长、参会人
   - **讨论要点**：按话题分组，每个话题 1~3 句话概括
   - **决策结论**：哪些事情达成了共识
   - **待办事项**：谁、做什么、什么时候完成
   - 如果转写中有明确的发言人标注，在纪要中保留"XX 提出 / XX 建议"
8. 对待办事项进行交叉检查：如果原文只说"这个事情要跟进"但没指定人，标注 [负责人待定]

### 阶段四：输出与归档（可选）
9. 将纪要发送给用户
10. 如果用户说"帮我存到飞书文档里"，使用 `lark-cli docs +create` 创建一个飞书文档，写入纪要内容

## 输出格式

**会议纪要**

- 会议：[会议名称]
- 日期：[日期] | 时长：[XX 分钟]
- 参会人：[参会人列表]

**讨论要点**
1. **[话题 1]**：[讨论内容概要]
2. **[话题 2]**：[讨论内容概要]

**决策结论**
- [结论 1]
- [结论 2]

**待办事项**

| 事项 | 负责人 | 截止日期 |
|------|--------|---------|
| [具体任务] | [姓名] | [日期] |
