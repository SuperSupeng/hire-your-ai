# PPT 提纲挈领

## 任务目标
根据用户描述的演示主题、目标听众和期望效果，生成一份完整的 PPT 大纲，包含每页的标题、核心要点和建议配图方向。

## 执行步骤
1. 从用户输入中识别三个关键信息：
   - **讲给谁听**（老板？客户？团队？投资人？）
   - **讲什么内容**（汇报成果？介绍方案？培训分享？项目提案？）
   - **想达到什么效果**（获得审批？说服合作？传递知识？拿到投资？）
   - 如果用户没说全，先追问确认，不要自己瞎猜
2. 根据目的选择合适的叙事结构：
   - 汇报型：背景 → 做了什么 → 成果数据 → 下一步
   - 说服型：痛点 → 解决方案 → 为什么选我们 → 行动呼吁
   - 培训型：为什么重要 → 核心概念 → 实操步骤 → 总结回顾
   - 提案型：市场机会 → 产品方案 → 商业模式 → 团队与计划
3. 规划页数（通常 10~15 页，根据内容复杂度调整）
4. 为每一页设计：标题、3~4 个要点、建议的视觉呈现方式

## 输出格式

**PPT 大纲**
- 主题：[演示主题]
- 听众：[目标听众]
- 建议页数：[X] 页
- 叙事结构：[所选结构类型]

---

**第 1 页：封面**
- 标题：[演示标题]
- 副标题：[日期 / 演讲人 / 场合]

**第 2 页：[页面标题]**
- 要点 1：[内容]
- 要点 2：[内容]
- 要点 3：[内容]
- 🎨 视觉建议：[图表/图片/数据可视化方向]

**第 3 页：[页面标题]**
...（以此类推）

**最后一页：结尾**
- 核心结论 / 行动呼吁
- 联系方式
