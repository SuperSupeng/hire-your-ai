# 2.1 去云端领一把"大脑钥匙"(API Key)

> 🎯 **本节目标**:拿到一把能激活云端大模型的"钥匙",这是数字员工长出大脑的第一步。

## 你需要理解一件事:大脑不在你电脑里

你可能以为"装一个数字员工"像装微信一样——下个软件就完了。其实不是。

**数字员工的"躯壳"在你电脑里,但它的"大脑"(大语言模型)跑在远方的云端超级服务器上**。你需要一把钥匙,才能让你本地的躯壳连上云端的大脑。这把钥匙就叫 **API Key**。

不要害怕这个英文单词。获取它的流程,**和注册一个淘宝账号一样简单**。

---

## 选一个服务商(三选一,推荐智谱)

不同的服务商对应不同风格的"大脑":

| 服务商 | 特点 | 新手推荐 |
|---|---|---|
| **智谱 AI (GLM)** | 国内服务,注册即送大量免费额度,无需翻墙 | ⭐ 强烈推荐 |

---

## 三步拿到钥匙

### 第一步 · 注册账号

打开浏览器,访问智谱大模型开放平台(`[此处补充实际链接]`),用手机号注册并登录。

> 🖼️ *[此处预留:智谱开放平台注册页截图]*

### 第二步 · 生成钥匙

登录后,点击右上角的 **"API Keys"** 菜单,然后点击 **"添加新的 API Key"**。

屏幕上会立刻出现一串长长的字符,形如:

```
sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

这就是你的**大脑钥匙**。

> 🖼️ *[此处预留:智谱平台生成 API Key 的截图]*

### 第三步 · 复制并妥善保管

⚠️ **重要**:这串字符等同于你的信用卡密码。

1. **立刻复制**,粘贴到你的备忘录或密码管理器里(1Password、Bitwarden 等)。
2. **千万不要**发给别人、贴到 GitHub、或者截图发朋友圈。
3. **千万不要**硬编码到代码里并 push 到公开仓库。

如果钥匙泄露,立刻回到平台"吊销(Revoke)"这把钥匙,然后重新生成一把。

## 💰 成本焦虑速答

**"用一次要多少钱?"**

数字员工每帮你读一篇文章、写一份报告,成本大约在**几分钱到几毛钱人民币**之间。

就算它每天帮你干 10 件事,一个月下来大概也就一杯奶茶钱。**比雇真人便宜一万倍**。

**"会不会被刷爆?"**

不会。平台都有**额度上限 + 短信提醒**,你可以在控制台里主动设置每月预算上限。新手跟着教程跑完全程,基本用的都是注册赠送的免费额度。
