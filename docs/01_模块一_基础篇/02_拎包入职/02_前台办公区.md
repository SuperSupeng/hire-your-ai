# 2.2 搭建"前台办公区":OpenClaw 极简安装

> 🎯 **本节目标**:下载并安装你的第一台"办公软件",让数字员工有一个能坐下来的前台。

## 什么是"前台"?

把数字员工的工作环境想象成一家公司:

- **前台** = 用户(也就是你)日常和员工打交道的地方。你在这里发消息、看回复、验收成果。
- **后台** = 员工自己装备大脑、接入技能、配置工作流的后厨(下一节讲)。

这一节,我们先装"前台"。

---

## 选一个前台:OpenClaw vs Hermes

我们为你准备了两套现成的前台软件,功能都能跑通本教程。**凭直觉任选其一即可**:

| 软件 | 气质 | 适合谁 |
|---|---|---|
| **OpenClaw** | 像微信,所有互动都在聊天框里 | 喜欢聊天 UI、想接入微信/飞书的同学 |
| **Hermes** | 像桌面应用,多面板布局 | 喜欢沉浸式桌面工具的同学 |

> 💡 **本教程以 OpenClaw 为主线**。选 Hermes 的同学,大部分操作完全对称,只是菜单位置不同。

---

## OpenClaw 三步安装

### 第一步 · 下载

1. 打开浏览器,访问 OpenClaw 官方下载页:`[此处补充实际下载链接]`
2. 根据你的电脑系统选择对应安装包:
   - Windows → `.exe`
   - macOS → `.dmg`
   - Linux → `.AppImage`

> 🖼️ *[此处预留:OpenClaw 官网下载按钮截图]*

### 第二步 · 安装

- **Windows**:双击 `.exe`,一路"下一步(Next)"。
- **macOS**:双击 `.dmg`,把 OpenClaw 图标拖进"应用程序(Applications)"。
- **Linux**:`chmod +x` 后双击运行。

> ⚠️ **macOS 提示"无法验证开发者"?** 在 系统设置 → 隐私与安全性 → 底部点"仍要打开"即可。

### 第三步 · 首次启动

打开 OpenClaw,你会看到:

- 左侧导航栏(设置、渠道、技能、知识库……)
- 中间聊天窗口
- 右侧可能是当前 Agent 的信息面板

**恭喜,前台办公区已经搭好了。** 但此刻它还只是一个空壳——没有大脑、没有技能、没有连接任何聊天工具。
