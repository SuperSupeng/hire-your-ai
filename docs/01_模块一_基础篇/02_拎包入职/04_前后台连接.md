# 2.4 前后台连接:让员工进入你的微信/飞书

> 🎯 **本节目标**:打通 OpenClaw(后台)和你日常的聊天软件(前台入口),让数字员工真正进入你的工作流。

## 为什么要做这一步?

到现在为止,你的数字员工只住在 OpenClaw 软件里。想和它说话,你得**专门打开 OpenClaw**。

这不符合真实工作场景——你的老板、同事、客户都在**微信 / 飞书**里找你。数字员工也必须**住进那些地方**,才能真正被你随时召唤。

这一节,我们把它接入两个最常用的入口:

- **微信**(最接地气,适合个人/生活场景)
- **飞书**(最适合办公,企业场景首选)

---

## 接入微信(3 步完成)

### 步骤

1. 在 OpenClaw 左侧导航找到 **"渠道 (Channels)"** → **"微信 (WeChat)"**。
2. 点击 **"生成登录二维码"**。
3. 拿出手机,用微信 **扫码登录**。

✨ 滴!你的数字员工现在已经变成了:
- 你微信通讯录里的一个**好友**
- 或者某个群里能被 @ 的**助手**

> 🖼️ *[此处预留:OpenClaw 微信扫码界面截图]*

### 测试一下

在微信里找到刚登录的账号,直接发送:

> 调用【无情周报生成器】,我这周干了三件事:1. 搞定了新客户签约 2. 梳理了下半年规划 3. 组织了团队团建。帮我写一份周报。

几秒钟后,周报就会出现在你的微信里。**你的员工,已经住进你的手机了**。

## ⚠️ 【防封号指南】这一步极其重要!

微信官方对"机器人"的风控**非常严格**。踩坑了你的大号可能会被永久封禁——先看完本节再操作。

### 铁律三条

| 原则 | 为什么 |
|---|---|
| **1. 用小号扫码,不要用大号** | 主号被封影响生活社交,小号被封只是小损失 |
| **2. 控制频率,不要连发刷屏** | 被风控系统识别为"机器人行为"的主因 |
| **3. 办公场景首选飞书/企业微信** | 企业级平台对 API 机器人友好,基本不会封 |

### 更详细的安全清单

- ✅ 测试期间只在小群或和自己的大号对话
- ✅ 每次回复之间保留自然的停顿(1~3 秒)
- ✅ 关闭"自动回复所有消息"这种激进模式
- ❌ 不要让机器人在陌生人多的大群疯狂说话
- ❌ 不要用它发广告、营销信息
- ❌ 不要频繁切换登录设备

### 如果不幸被封了怎么办?

- 立即停用该账号的机器人接入
- 按微信引导申诉,说明"用于个人效率工具测试"
- **下次务必换小号,并遵守频率原则**

## 接入飞书(最适合长期办公)

飞书对机器人极其友好,**几乎不会封**,而且支持丰富的卡片消息格式(按钮、表格、图片)。

> 📖 **本节只讲概要**。飞书机器人的完整创建流程(申请 App ID、获取 App Secret、配置回调 URL 等)单开一节,详见下一节 [2.5 飞书机器人](./05_飞书机器人.md)。

概要流程:

1. 在飞书开放平台创建一个"自建应用",得到 `App ID` 和 `App Secret`。
2. 在 OpenClaw 的 **"渠道 → 飞书"** 中,填入这两个凭证。
3. 点击保存,你的飞书企业架构里就多了一位不知疲倦的新同事。

具体手把手步骤见下一节。
