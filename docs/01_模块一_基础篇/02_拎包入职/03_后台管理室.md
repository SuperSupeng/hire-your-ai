# 2.3 走进"后台管理室":装大脑 + 挂技能

> 🎯 **本节目标**:在 OpenClaw 后台装上大脑(接入 API Key),并导入"新手大礼包"让它立刻会干活。

## 什么是"后台"?

**后台管理室**,就是数字员工装备自己的地方:

- 🧠 装上**大脑**(接入大模型 API)
- 🧰 挂上**技能**(导入 Skill/Agent 包)
- 📚 喂入**记忆**(挂载知识库 · 模块三再展开)

这一节,我们装好前两样——大脑 + 技能。

---

## Part 1 · 装大脑:接入 API Key

还记得上一节你从智谱领到的那把钥匙(`sk-xxx...`)吗?现在是它上场的时候。

### 步骤

1. 打开 OpenClaw,点击左下角 **"设置 (Settings)"** → **"模型配置 (Models)"**。
2. 在对应的服务商(比如"智谱 AI")一栏,把你的 API Key **粘贴**进去。
3. 点击 **"测试连接"**。
4. 看到绿色的 **"Success"** 提示,说明大脑接入成功!🎉

> 🖼️ *[此处预留:OpenClaw 模型配置界面 + 粘贴 API Key 截图]*

### 如果失败了?

| 错误信息 | 可能原因 | 怎么办 |
|---|---|---|
| `Invalid API Key` | Key 复制漏了字符 / 用的是旧 Key | 回平台重新复制 |
| `Insufficient quota` | 免费额度用完 | 充值 5 元可以用很久 |
| `Network error` | 网络问题(海外服务商常见) | 换国内服务商或配代理 |

## Part 2 · 挂技能:领取"新手大礼包"

员工装上大脑了,但它现在就像刚入职的应届生——**能听懂话,但不会干活**。

为了让你快速体验到"数字员工的能力",我们为你准备了一个 **新手大礼包**,里面有三个开箱即用的职场高频技能。

### 🎁 大礼包内容

| 技能 | 它能做什么 |
|---|---|
| **爆款文案写手** | 丢一个网页链接,自动提取要点 + 改写成带 Emoji 的小红书推文 |
| **无情周报生成器** | 丢几句流水账,自动扩写成结构清晰的周报 |
| **会议纪要提炼师** | 丢一段会议语音转文字,自动提取结论和 To-Do |

### 如何导入

👉 **下载地址**:`[此处插入新手大礼包 .zip 或 .json 链接]`

1. 下载并解压大礼包。
2. 在 OpenClaw 左侧导航找到 **"技能 (Skills)"**。
3. 点击右上角 **"导入 (Import)"**,选择解压出的 `.json` 文件。
4. 搞定——员工瞬间拥有了这三项专业技能。

## 🎁 彩蛋:顺便装一个"人设灵魂"

在大礼包里,我们还附送了一个 **[专属人设灵魂 · 首席打杂官]**:

导入后,它不再是冷冰冰的"助手",而是会用以下方式回复你:

> "老板好,我是你的首席打杂官。今天有什么体力活交给我?"

导入方式:在 **"Agent"** 菜单点"导入人设",选择 `首席打杂官.md` 即可。

模块三我们会教你怎么**自己写人设**,让员工变成任意角色:财务分析师、公关写手、甚至"温柔的秘书刘亦菲"。
