## 6. 进阶架构：从单兵作战到集团军
你现在拥有了一个有记忆、有技能、懂你语气的数字员工。它能干活了，而且干得越来越像你。
但当你想让它做更复杂的事时，你会碰到一个瓶颈：**一个全能型选手，往往不如几个专才配合。** 就像你不会让主编去排版，也不会让实习生去定战略——专业的事，交给专业的角色。
这一章，我们来玩点更大的：让多个数字员工组队，像真正的团队一样分工协作。
> 💡 如果你的数字员工某天突然"罢工"了（定时任务没跑、报错、不理你），别慌——翻到**附录 A：疑难杂症门诊**，按"闹钟→手脚→大脑→问 AI"四步排查，90% 的问题都能解决。

#### 动手实操：在 Cursor 里搭建一个最小协作流
最简单的多 Agent 协作，不需要复杂的工作流系统——**用技能文件里的执行步骤把它们串起来就行**。
**第一步：创建三个员工身份**
在 Cursor 的 `agents/` 目录下，分别创建三个身份文件：
```plaintext
agents/
├── 首席打杂官.md          ← 你原有的通用助手
├── researcher.md          ← "你是一个情报研究员，擅长高效搜索和信息提炼..."
├── writer.md              ← "你是一个金牌撰稿人，擅长把信息写成生动文章..."
└── editor.md              ← "你是一个毒舌主编，对文字质量极度苛刻..."

```

**第二步：创建"生产线"技能**
在 `skills/` 目录下新建 `daily_report_pipeline.md`：
```markdown
---
name: daily_report_pipeline
description: 行业日报自动生产线（三人协作）
trigger:
  cron: "0 7 * * *"
tools:
  - web_search
output:
  channel: feishu
---

# 行业日报生产线

## 协作流程

### 第一棒：情报研究员
1. 使用联网搜索，检索今天 AI、创投、大厂领域的最新新闻
2. 筛选出 10 条最有价值的，每条写一句话摘要
3. 输出格式：编号列表，每条包含【标题】和【一句话摘要】

### 第二棒：金牌撰稿人
1. 从上面 10 条中，挑出最值得深度解读的 3 条
2. 结合知识库中的行业背景资料，为每条写一段 200 字左右的深度点评
3. 语气要求：口语化，有观点，禁止使用"总之""综上"

### 第三棒：毒舌主编
1. 审阅撰稿人的输出，检查以下问题：
   - 是否有事实性错误？（有则标注 ⚠️）
   - 是否有"AI味"套话？（有则改写）
   - 排版是否适合手机阅读？
2. 加上日报标题、日期、结尾 slogan
3. 最终输出完整的日报，发送到飞书

```

> 💡 **你发现了吗？** 这个技能文件跟之前写的单人技能，结构完全一样——还是 `配置头 + 执行步骤 + 输出格式`。唯一的区别是，执行步骤里按角色分成了"第一棒、第二棒、第三棒"。大模型会自动按顺序切换角色来执行。
**第三步：验收**
保存文件，去飞书里 @你的数字员工，说"立刻执行一次【行业日报生产线】"。你会看到输出里明显有三个阶段的痕迹——先是干巴巴的新闻列表，然后是有血有肉的点评，最后是排版精美的成品。
这就是多 Agent 协作的最小可运行版本。
