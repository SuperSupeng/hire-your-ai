# 附录
## A. 疑难杂症门诊：数字员工罢工了怎么办？
数字员工不是神，它也会遇到网络波动、接口超时、或者"听不懂人话"的时候。当你发现"咦，今天早上怎么没收到报告？"时，不要慌，按以下步骤在 Cursor（后台）里当一次"老中医"：

<lark-table rows="5" cols="4" header-row="true" column-widths="183,183,183,183">

  <lark-tr>
    <lark-td>
      排查顺序
    </lark-td>
    <lark-td>
      检查什么
    </lark-td>
    <lark-td>
      常见问题
    </lark-td>
    <lark-td>
      怎么修
    </lark-td>
  </lark-tr>
  <lark-tr>
    <lark-td>
      ① 闹钟
    </lark-td>
    <lark-td>
      技能文件里的 `trigger` / `cron` 表达式
    </lark-td>
    <lark-td>
      `0 9 * * 1` 是每周一早 9 点，如果写成 `9 0 * * 1` 就变成了凌晨 0:09
    </lark-td>
    <lark-td>
      修正 cron 表达式，保存即可
    </lark-td>
  </lark-tr>
  <lark-tr>
    <lark-td>
      ② 手脚
    </lark-td>
    <lark-td>
      技能文件里的 `tools` 配置
    </lark-td>
    <lark-td>
      报错"无法获取网页内容"——可能没写 `web_search`，或目标网站有反爬
    </lark-td>
    <lark-td>
      检查 tools 列表，或者换一个信息源
    </lark-td>
  </lark-tr>
  <lark-tr>
    <lark-td>
      ③ 大脑
    </lark-td>
    <lark-td>
      API Key 是否正常
    </lark-td>
    <lark-td>
      提示 `Unauthorized` 或完全不理你——大概率 API Key 欠费或填错
    </lark-td>
    <lark-td>
      去大模型平台检查余额，重新复制粘贴 Key
    </lark-td>
  </lark-tr>
  <lark-tr>
    <lark-td>
      ④ 问 AI
    </lark-td>
    <lark-td>
      把报错信息扔给 Cursor AI
    </lark-td>
    <lark-td>
      你看不懂的错误，Cursor AI 大概率能看懂
    </lark-td>
    <lark-td>
      按 `Cmd/Ctrl + I`，把报错截图或日志发给它，让它帮你排查
    </lark-td>
  </lark-tr>
</lark-table>

> 📌 **记住排查顺序：闹钟 → 手脚 → 大脑 → 问 Cursor AI。** 90% 的"罢工"都是这四个原因之一。
